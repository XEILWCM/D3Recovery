<h3 align="center"><a href="https://doi.org/10.1002/mp.70661">Paper</a> | <a href="https://pubmed.ncbi.nlm.nih.gov/42740403/">PubMed</a> | <a href="https://xeilwcm.github.io/D3Recovery/">Project Page</a> | <a href="https://xeilwcm.github.io/D3Recovery/#video">Video</a></h3>

We recover where an inter-crystal scattered photon first interacted, in crystal
and depth, with a diffusion-driven and physics-informed pipeline trained on data
from one scanner-level experiment and one simulation. On real phantom scans this
keeps roughly 70% of coincidences that would otherwise be thrown away, while
restoring much of the resolution lost to mispositioning.

This repository holds the project page, served by GitHub Pages at
https://xeilwcm.github.io/D3Recovery/.
